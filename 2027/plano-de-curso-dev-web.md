# Plano de Curso — Dev: Programação Web Frontend e Backend

## 1) Descrição do curso

**Nome:** Dev — Programação Web Frontend e Backend  
**Carga horária:** 72 horas  
**Formato:** 1 aula por semana, às quartas-feiras, com 1h30 de duração  
**Duração:** um ano letivo — 48 semanas de aula + 4 semanas de reserva para recesso, feriados e reposição  
**Modalidade:** presencial ou online ao vivo  
**Nível:** iniciante

**Objetivo geral:** preparar o aluno para entender como a web funciona e desenvolver aplicações frontend e backend com JavaScript, usando lógica de programação, bibliotecas, frameworks e um ambiente moderno de desenvolvimento.

**Objetivos específicos:**

- Entender web, servidor, HTTP, arquivos, pastas e publicação de sites.
- Desenvolver lógica de programação com JavaScript.
- Criar interfaces com HTML, CSS e React.
- Construir APIs e servidores com Node.js e Express.
- Usar VS Code, Git, GitHub, npm e ferramentas modernas.
- Publicar um projeto full stack e montar portfólio.

**Metodologia:**

- Cada aula trata de **um único assunto**.
- Organização da aula: 10 min de revisão, 20 min de teoria/demonstração, 50 min de prática e 10 min de desafio.
- Exercícios semanais e projeto final.
- Estudo extra recomendado: 3 a 5 horas por semana.

**Avaliação:**

- Práticas avaliadas nas semanas **6, 14, 21, 28, 35 e 43**.
- Projeto final nas semanas **46 a 48**.
- Certificado: **75% de presença** + projeto final publicado.

**Pré-requisitos:**

- Informática básica: arquivos, pastas, internet e e-mail.
- Raciocínio lógico.
- Leitura básica de inglês para documentação, com apoio.

**Observação importante:** o curso entrega a base e um projeto de portfólio. A entrada no mercado depende de prática contínua, novos projetos e participação em processos seletivos.

---

## 2) Público-alvo

- Jovens e adultos a partir de 16 anos.
- Pessoas sem experiência em programação que querem iniciar na área de desenvolvimento web.
- Quem já fez o curso de informática básica ou tem conhecimentos equivalentes.
- Pessoas em transição de carreira para frontend, backend ou desenvolvimento full stack.
- Estudantes que buscam estágio ou primeira oportunidade como desenvolvedor júnior.

---

## 3) Materiais

**Computador:**

- 8 GB de RAM no mínimo; 16 GB recomendado.
- Internet.
- Windows, macOS ou Linux.

**Softwares:**

- VS Code.
- Git.
- Node.js LTS.
- npm.
- Navegador Google Chrome ou Mozilla Firefox.
- SQLite e DB Browser for SQLite.
- Postman, Insomnia ou Thunder Client.
- React + Vite e Express.
- Conta GitHub.
- Contas gratuitas na Vercel/Netlify e Render/Railway.
- Terminal: PowerShell, Git Bash ou terminal do VS Code.

**Material do aluno:**

- Caderno e caneta.
- Fones de ouvido.
- Conta de e-mail.
- Tempo de estudo extra.

**Material do professor:**

- Projetor ou TV.
- Repositório de exemplos.
- Exercícios e desafios.
- Roteiros e listas de presença.

---

## Observações

- A ordem dos conteúdos pode ser ajustada conforme o ritmo da turma.
- As aulas devem equilibrar teoria curta e prática intensa no computador.
- O aluno deve manter um repositório no GitHub com os exercícios e o projeto final.
- O projeto final deve integrar frontend, backend, banco de dados e deploy.
- Recomenda-se revisar o conteúdo da aula anterior nos primeiros 10 minutos de cada encontro.
