# Aula: Fundamentos do Kubernetes e Primeiro Pod

O **Kubernetes (K8s)** é uma plataforma open-source projetada para automatizar a implantação, o dimensionamento e o gerenciamento de aplicações em contêineres. Ele atua como um maestro que garante que os contêineres estejam sempre rodando, saudáveis e escalados conforme a demanda.

---

## 1. Sabores do Kubernetes

Dependendo do ambiente e objetivo, existem diferentes distribuições ("sabores") do Kubernetes:

* **Desenvolvimento Local:**
* **MicroK8s:** Leve, focado em facilidade de uso, mantido pela Canonical (ideal para Ubuntu/Linux).
* **Minikube:** Cria um cluster de nó único em uma VM ou container local.
* **KIND (Kubernetes in Docker):** Roda o cluster Kubernetes utilizando contêineres Docker como nós.
* **K3s:** Distribuição leve mantida pela Rancher, excelente para IoT, Edge e ambientes com recursos limitados.


* **Produção (Self-Hosted):**
* **Kubeadm:** Ferramenta oficial para bootstrapar e gerenciar o ciclo de vida de clusters Kubernetes do zero em servidores próprios ou VMs.


* **Nuvem Gerenciada (Managed Services):**
* **EKS** (AWS), **GKE** (Google Cloud), **AKS** (Microsoft Azure).



---

## 2. Principais Objetos

A arquitetura do Kubernetes é baseada em objetos declarativos que representam o estado do cluster:

| Objeto | Descrição |
| --- | --- |
| **Container** | A aplicação empacotada com suas dependências (ex: imagem Docker `nginx`). |
| **Pod** | A menor unidade do K8s. Encapsula um ou mais contêineres que compartilham IP, rede e volumes. |
| **ReplicaSet** | Garante que um número específico de réplicas de Pods esteja rodando ao mesmo tempo. |
| **Deployment** | Gerencia a atualização declarativa de Pods e ReplicaSets, permitindo *rollouts* e *rollbacks*. |

---

## 3. Prática: Manipulação de Pods via CLI

Nesta atividade prática, você criará e gerenciará um Pod executando a imagem `nginx`.

> **Atenção:** Substitua `SEU_NOME` pelo seu primeiro nome nos comandos abaixo (ex: `pod-nginx-joao`).

### Passo 1: Criar o Pod

Utilize o comando `kubectl run` para subir o Pod diretamente pela linha de comando:

```bash
kubectl run pod-nginx-SEU_NOME --image=nginx

```

### Passo 2: Listar os Pods

Verifique se o Pod foi criado e qual o seu status atual (`ContainerCreating` ou `Running`):

```bash
kubectl get pod

```

### Passo 3: Listar com Informações Expandidas

Para visualizar o IP do Pod e em qual nó ele está rodando, utilize a flag `-o wide`:

```bash
kubectl get pod -o wide

```

### Passo 4: Detalhar o Pod

Exiba todos os eventos, status e configurações detalhadas do objeto:

```bash
kubectl describe pod pod-nginx-SEU_NOME

```

### Passo 5: Acessar o Terminal do Container

Entre no container em execução dentro do Pod para executar comandos no Shell (`bash`):

```bash
kubectl exec -it pod-nginx-SEU_NOME -- bash

```

*(Para sair do container, digite `exit`)*.

### Passo 6: Excluir o Pod

Remova o Pod do cluster ao finalizar o teste:

```bash
kubectl delete pod pod-nginx-SEU_NOME

```
