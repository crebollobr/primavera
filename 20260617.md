# Roteiro de Aula: Instalação e Gerenciamento de Pacotes no Linux

Nesta aula prática, vamos aprender como gerenciar e instalar pacotes em um ambiente baseado em Linux utilizando o gerenciador de pacotes `apt`. Para garantir total segurança e isolamento, realizaremos os testes dentro de um contêiner Docker temporário.

---

## Passo 1: Acessar o Servidor do Laboratório

Conecte-se ao servidor do laboratório via SSH utilizando o comando abaixo:

```bash

ssh aluno@ssh.chr.eti.br

ssh lab

```

> 
> **Nota:** A senha de acesso será fornecida pelo professor em sala.
> 
> 

## Passo 2: Criar um Ambiente de Testes Isolado (Docker)

Para não modificar as configurações do servidor principal, vamos iniciar um contêiner Ubuntu isolado. Esse ambiente será totalmente descartado assim que terminarmos a prática:

```bash
docker run -ti --rm ubuntu bash

```

## Passo 3: Atualizar o Índice de Pacotes

Antes de instalar qualquer software no Linux, é uma boa prática atualizar a lista local de pacotes do sistema para garantir que vamos baixar as versões mais recentes:

```bash
apt update

```

## Passo 4: Instalar os Pacotes Necessários

Vamos instalar as ferramentas que utilizaremos para subir e testar o nosso servidor web.

* **Instalar o Servidor Web Nginx:** Execute `apt install nginx` e confirme digitando `y` quando solicitado pelo terminal.


* **Instalar o Curl:** Execute `apt install curl`  para podermos realizar requisições HTTP e testar páginas diretamente pelo terminal.


* **Instalar o Wget:** Execute `apt install -y wget`  para permitir o download de arquivos diretamente da internet.


* **Instalar o Python 3:** Execute `apt install python3`  para podermos rodar scripts utilitários de sistema.



> ⚠️ **Atenção na Configuração de Fuso Horário (Timezone):** Durante a instalação do Python, o instalador perguntará a sua localização para ajustar o relógio do sistema. Responda digitando os números correspondentes:
> 1. Para **Geographic area**, digite `2` (America) e aperte Enter.
> 2. Para **Time zone**, digite `135` (Sao_Paulo) e aperte Enter.
> 
> 

## Passo 5: Configurar o Simulador do Systemctl

Como estamos executando o Ubuntu dentro de um contêiner Docker minimalista, o gerenciador de serviços padrão (`systemd`) não vem ativado por padrão. Para conseguirmos iniciar serviços com o comando `systemctl`, vamos baixar e configurar um script que simula essa função:

```bash
wget https://raw.githubusercontent.com/gdraheim/docker-systemctl-replacement/master/files/docker/systemctl3.py -O /usr/bin/systemctl

```

Agora, precisamos dar permissão de execução para que o sistema reconheça o script como um comando válido:

```bash
chmod +x /usr/bin/systemctl

```

## Passo 6: Iniciar e Testar o Nginx

Com o ambiente pronto, vamos colocar o nosso servidor web para funcionar e validar o acesso.

* **Iniciar o serviço do Nginx:** Execute `systemctl start nginx`.


* **Verificar o status do serviço:** Execute `systemctl status nginx`  para garantir que ele está ativo (running).


* **Testar o acesso local:** Execute `curl localhost`. Se tudo estiver correto, você verá a estrutura em HTML da página padrão de boas-vindas do Nginx impressa na sua tela.

## 💡 Dica de Ouro: Como remover pacotes?

Caso você precise desinstalar um software instalado pelo `apt` no futuro, existem duas abordagens principais:

* **`apt remove <nome_do_pacote>`**: Remove os arquivos binários do programa, mas mantém os arquivos de configuração salvos no sistema (caso decida reinstalá-lo mais tarde).
* **`apt purge <nome_do_pacote>`**: Remove completamente o programa do sistema, limpando inclusive todos os arquivos de configuração e dependências associadas.
