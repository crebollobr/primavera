# O que é DevOps?

**DevOps** é a junção de **"Development" (Desenvolvimento)** e **"Operations" (Operações)**. Mais do que uma ferramenta ou um cargo específico, o DevOps é uma **cultura** e uma filosofia de trabalho que visa unificar a equipa que cria o software (Dev) com a equipa que coloca esse software no ar e garante a sua estabilidade (Ops).

Antes do DevOps, estas duas equipas costumavam trabalhar isoladas (em "silos"), o que gerava lentidão, falhas de comunicação e bugs frequentes no sistema.

---

## Os Três Pilares do DevOps

Para entender o DevOps na prática, ele baseia-se em três frentes principais:

* **Cultura:** Foco em colaboração, transparência e responsabilidade partilhada. Se o sistema falha, o problema não é de uma equipa isolada, é de todos.
* **Processos:** Automação de tarefas repetitivas e entregas menores e mais frequentes. Em vez de lançar uma atualização gigante uma vez por ano, lançam-se pequenas atualizações todas as semanas ou todos os dias.
* **Ferramentas:** Softwares que ajudam a automatizar todo o ciclo de vida do desenvolvimento (como Docker, Jenkins, Kubernetes, Git, etc.).

---

## O Ciclo DevOps (O "Infinito")

O processo DevOps é visualizado como um símbolo do infinito porque o trabalho nunca para: é um ciclo contínuo de feedback e melhoria.

1.  **Planear e Codificar:** Os desenvolvedores planeiam as funcionalidades e escrevem o código.
2.  **Construir e Testar (CI - Integração Contínua):** O código é compilado e testado automaticamente para garantir que nada foi quebrado.
3.  **Implantar (CD - Entrega Contínua):** O software é enviado para o ambiente de produção (onde o utilizador final mexe) de forma rápida e segura.
4.  **Operar e Monitorizar:** A equipa acompanha o sistema em tempo real para corrigir qualquer erro ou lentidão imediatamente, gerando dados para o próximo planeamento.

---

## Principais Benefícios

* 🚀 **Velocidade:** Empresas que usam DevOps lançam produtos e atualizações no mercado muito mais rápido.
* 🛡️ **Confiabilidade:** Como os testes são automatizados, o risco de o sistema falhar após uma atualização diminui drasticamente.
* 🔄 **Recuperação Rápida:** Se algo der errado, é muito mais fácil identificar o erro e reverter o sistema para a versão anterior estável (rollback).
