**Roteiro Prático: Criando e Exportando Serviços com Docker**

**1. Acesso ao Servidor e Verificação**

Conecte-se ao ambiente de laboratório via terminal e verifique os containers ativos:

```bash
ssh aluno@ssh.chr.eti.br
ssh lab
docker ps

```

---

**2. Teoria Essencial: Portas de Rede e Volumes**

* **Portas de Rede (`-p`):** O IP do servidor identifica a máquina na rede, enquanto a **porta** indica qual serviço vai responder.
* O serviço web sem criptografia utiliza a **porta 80** (HTTP) por padrão.
* Como o container roda isolado, usamos a flag `-p` para mapear o tráfego do servidor para o container: `-p PORTA_DO_SERVIDOR:PORTA_DO_CONTAINER`.
* Como todos utilizam o mesmo servidor, **cada aluno terá uma porta pública exclusiva no servidor** (ex: `8081`, `8082`), direcionando para a porta `80` interna do seu Nginx.


* **Volumes (`-v`):** Containers são efêmeros (se o container for destruído, os dados internos somem).
* O **Volume** vincula uma pasta do servidor real (host) a uma pasta interna do container: `-v PASTA_DO_SERVIDOR:PASTA_DO_CONTAINER`.
* Isso garante a persistência dos dados e permite alterar o código no servidor sem precisar recriar o container.



---

**3. Criando a Estrutura de Arquivos no Servidor**

Crie um diretório exclusivo em `/tmp/` para armazenar a sua página web personalizada:

```bash
# 1. Crie e acesse sua pasta individual
mkdir /tmp/[seu_nome]
cd /tmp/[seu_nome]

# 2. Abra o editor nano para criar o index.html
nano index.html

```

Dentro do editor `nano`, digite o código HTML:

```html
<h1>Boa Noite, [seu_nome]</h1>

```

*Para salvar e sair:* Pressione `Ctrl + O`, aperte `Enter` para confirmar e pessione `Ctrl + X`.

---

**4. Subindo o Container Nginx com Porta e Volume**

O Nginx busca páginas por padrão no caminho interno `/usr/share/nginx/html`. Execute o comando substituindo `[seu_nome]` e `[sua_porta]`:

```bash
docker run -d --name [seu_nome] -p [sua_porta]:80 -v /tmp/[seu_nome]:/usr/share/nginx/html nginx

```

* `-d`: Executa o container em segundo plano.
* `--name [seu_nome]`: Define o nome do container.
* `-p [sua_porta]:80`: Conecta a sua porta pública à porta 80 do Nginx.
* `-v /tmp/[seu_nome]:/usr/share/nginx/html`: Mapeia seu diretório local para a pasta web do Nginx.

---

**5. Validação via Terminal com `curl**`

1. Confirme que o container está ativo:
```bash
docker ps

```


2. Faça a requisição HTTP direta via terminal usando o `curl`:
```bash
curl localhost:[sua_porta]

```


*O terminal deve retornar o HTML:* `<h1>Boa Noite, [seu_nome]</h1>`
3. **Teste a dinâmica do Volume:** Altere o arquivo diretamente no servidor via `nano` sem encostar no container:
```bash
echo "<h1>Boa Noite, [seu_nome] - Atualizado!</h1>" > /tmp/[seu_nome]/index.html

```


4. Execute o `curl` novamente:
```bash
curl localhost:[sua_porta]

```


*O resultado será atualizado imediatamente no terminal, provando que o volume reflete as alterações em tempo real.*
