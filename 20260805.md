# Aula de Revisão de Linux

## Objetivos

Ao final desta prática, você deverá saber:

- Acessar o servidor do laboratório via SSH.
- Criar um ambiente isolado usando Docker.
- Navegar pelo sistema de arquivos.
- Criar, listar, copiar e remover arquivos e diretórios.
- Alterar permissões de arquivos.
- Criar e executar um script Bash.
- Instalar, utilizar e remover um programa.
- Usar comandos encadeados com `|`, `>`, `<` e `grep`.

---

## 1. Acessar o servidor do laboratório

Abra um terminal no seu computador e conecte-se ao servidor:

```bash
ssh aluno@ssh.chr.eti.br
```

Depois de acessar o servidor, conecte-se ao ambiente de laboratório:

```bash

```

A senha será fornecida pelo professor em sala.

Para confirmar em qual máquina você está:

```bash
hostname
```

Para verificar o usuário atual:

```bash

```

Para verificar o diretório atual:

```bash
pwd
```

O comando `pwd` mostra o caminho completo do diretório em que você está trabalhando.

## 2. Criar um ambiente de testes isolado com Docker

Para evitar alterações no sistema principal do laboratório, vamos iniciar um contêiner Ubuntu:

```bash
docker run -ti --rm ubuntu bash
```

Esse comando significa:

- `docker run`: cria e inicia um contêiner.
- `-t`: cria um terminal interativo.
- `-i`: mantém a entrada do terminal aberta.
- `--rm`: remove o contêiner quando ele for encerrado.
- `ubuntu`: utiliza uma imagem Ubuntu.
- `bash`: inicia o interpretador de comandos Bash.

Agora confirme o usuário dentro do contêiner:

```bash
whoami
```

O resultado esperado é:

```text
root
```

Isso significa que você possui privilégios administrativos **dentro do contêiner**. O acesso de `root` não significa que você tenha controle sobre o servidor principal ou sobre outros contêineres.

Verifique o sistema operacional:

```bash
cat /etc/os-release
```

Verifique o nome do contêiner:

```bash
hostname
```

## 3. Conhecendo o sistema de arquivos

O Linux organiza seus arquivos em uma estrutura hierárquica. O diretório inicial dessa estrutura é representado por `/`.

Confira o conteúdo do diretório atual:

```bash
ls
```

Use uma listagem detalhada:

```bash
ls -l
```

Inclua arquivos ocultos:

```bash
ls -la
```

Uma forma bastante utilizada é:

```bash
ls -lah
```

As opções significam:

- `-l`: exibe detalhes dos arquivos.
- `-a`: exibe arquivos ocultos.
- `-h`: exibe tamanhos em formato legível.

Para listar o diretório raiz:

```bash
ls /
```

Para listar o diretório `/tmp`:

```bash
ls /tmp
```

## 7. Escrever conteúdo em arquivos

Use o comando `echo` para escrever uma linha:

```bash
echo "Primeira linha da aula de Linux"
```

Para salvar a saída em um arquivo, utilize `>`:

```bash
echo "Primeira linha da aula de Linux" > anotacoes.txt
```

Confira o conteúdo:

```bash
cat anotacoes.txt
```

O operador `>` cria o arquivo caso ele não exista. Se o arquivo já existir, seu conteúdo será substituído.

Adicione uma nova linha sem apagar o conteúdo existente usando `>>`:

```bash
echo "Segunda linha da aula de Linux" >> anotacoes.txt
```

Confira novamente:

```bash
cat anotacoes.txt
```

Adicione mais algumas linhas:

```bash
echo "Linux possui arquivos, diretórios e permissões" >> anotacoes.txt
echo "O Bash interpreta os comandos digitados" >> anotacoes.txt
echo "Docker permite criar ambientes isolados" >> anotacoes.txt
```

Exiba o arquivo numerando as linhas:

```bash
cat -n anotacoes.txt
```

## 9. Copiar, mover e remover arquivos

Crie um arquivo de exemplo:

```bash
echo "Arquivo original" > original.txt
```

Copie o arquivo:

```bash
cp original.txt copia.txt
```

Confira os dois arquivos:

```bash
ls -l
```

Leia a cópia:

```bash
cat copia.txt
```

Crie um diretório para organizar os arquivos:

```bash
mkdir backup
```

Mova a cópia para o diretório `backup`:

```bash
mv copia.txt backup/
```

Verifique o resultado:

```bash
ls -l
ls -l backup
```

Renomeie o arquivo movido:

```bash
mv backup/copia.txt backup/copia-seguranca.txt
```

Remova um arquivo:

```bash
rm original.txt
```

Verifique se ele foi removido:

```bash
ls -l
```

Remova um diretório vazio:

```bash
mkdir diretorio-vazio
rmdir diretorio-vazio
```

Para remover um diretório com seu conteúdo:

```bash
rm -r backup
```

> Tenha cuidado com `rm -r`. Esse comando remove arquivos e diretórios sem enviá-los para uma lixeira.

## 10. Permissões de arquivos

Crie um arquivo de teste:

```bash
echo "Arquivo de permissões" > permissoes.txt
```

Visualize suas permissões:

```bash
ls -l permissoes.txt
```

Um resultado semelhante a este pode ser exibido:

```text
-rw-r--r-- 1 root root 22 Jul 31 12:00 permissoes.txt
```

A primeira parte representa as permissões:

```text
-rw-r--r--
```

Ela pode ser interpretada assim:

```text
- rw- r-- r--
  │   │   │
  │   │   └── Outros usuários
  │   └────── Grupo
  └────────── Dono do arquivo
```

As permissões básicas são:

- `r`: leitura.
- `w`: escrita.
- `x`: execução.

Os grupos são:

- Usuário proprietário.
- Grupo proprietário.
- Outros usuários.

---

## 11. Alterar permissões com `chmod`

Remova a permissão de escrita dos outros usuários:

```bash
chmod o-w permissoes.txt
```

Confira as permissões:

```bash
ls -l permissoes.txt
```

Remova a permissão de escrita do grupo:

```bash
chmod g-w permissoes.txt
```

Adicione a permissão de execução para o proprietário:

```bash
chmod u+x permissoes.txt
```

A forma simbólica utiliza:

- `u`: usuário proprietário.
- `g`: grupo.
- `o`: outros usuários.
- `a`: todos os usuários.
- `+`: adiciona uma permissão.
- `-`: remove uma permissão.
- `=`: define exatamente as permissões.

Exemplo:

```bash
chmod u+rw arquivo.txt
```

Esse comando adiciona leitura e escrita para o proprietário.

Defina leitura e escrita para o proprietário e apenas leitura para grupo e outros:

```bash
chmod 644 permissoes.txt
```

O valor `644` representa:

```text
6 = leitura + escrita para o proprietário
4 = leitura para o grupo
4 = leitura para outros usuários
```

## 12. Criar um programa Bash

Entre no diretório de scripts:

```bash
cd /tmp/aula-linux/scripts
```

Crie o arquivo:

```bash
touch programa
```

Abra o arquivo com o editor `vi`:

```bash
vi programa
```

No editor `vi`:

1. Pressione `i` para entrar no modo de inserção.
2. Digite o conteúdo abaixo.
3. Pressione `Esc`.
4. Digite `:wq`.
5. Pressione `Enter`.

Conteúdo do arquivo:

```bash
#!/bin/bash

echo "Olá, mundo!"
echo "Este é o meu primeiro programa Bash."
```

A primeira linha é chamada de *shebang*:

```bash
#!/bin/bash
```

Ela informa que o arquivo deve ser executado usando o interpretador Bash.

Confira o conteúdo:

```bash
cat programa
```

---

## 13. Executar o programa Bash

Primeiro, verifique as permissões:

```bash
ls -l programa
```

Tente executar o arquivo:

```bash
./programa
```

É possível que o sistema exiba uma mensagem semelhante a:

```text
Permission denied
```

Isso ocorre porque o arquivo ainda não possui permissão de execução.

Adicione a permissão:

```bash
chmod u+x programa
```

Confira novamente:

```bash
ls -l programa
```

Execute o programa:

```bash
./programa
```

Saída esperada:

```text
Olá, mundo!
Este é o meu primeiro programa Bash.
```

O prefixo `./` informa que o programa está no diretório atual.

Também seria possível executar o script diretamente com o Bash:

```bash
bash programa
```

Nesse caso, a permissão de execução não é necessária, pois o próprio comando `bash` está lendo o arquivo.

## 15. Instalar o programa `bc`

O `bc` é uma calculadora de linha de comando.

Primeiro, atualize a lista de pacotes:

```bash
apt update
```

Instale o programa:

```bash
apt install -y bc
```

Verifique se ele está disponível:

```bash
which bc
```

Consulte a versão instalada:

```bash
bc --version
```

---

## 16. Usar o programa `bc`

Execute o programa:

```bash
bc
```

Digite algumas operações:

```text
2 + 2
10 * 5
100 / 4
```

Para sair do `bc`, pressione:

```text
Ctrl+D
```

Também é possível calcular diretamente com um comando:

```bash
echo "2 + 2" | bc
```

Calcule uma expressão mais complexa:

```bash
echo "10 / 3" | bc
```

Por padrão, o resultado da divisão pode ser exibido sem casas decimais. Para usar casas decimais:

```bash
echo "scale=2; 10 / 3" | bc
```

Saída esperada:

```text
3.33
```

Outro exemplo:

```bash
echo "scale=4; 22 / 7" | bc
```

## 18. Filtrar informações com `grep`

Crie um arquivo com nomes de comandos:

```bash
cat > comandos.txt <<'EOF'
ls
mkdir
touch
cd
chmod
grep
cut
cat
echo
EOF
```

Exiba o conteúdo:

```bash
cat comandos.txt
```

Procure a palavra `grep`:

```bash
grep grep comandos.txt
```

Procure todos os comandos que possuem a letra `c`:

```bash
grep c comandos.txt
```

Ignore diferenças entre letras maiúsculas e minúsculas:

```bash
grep -i C comandos.txt
```

Mostre o número da linha encontrada:

```bash
grep -n chmod comandos.txt
```

Conte quantas linhas contêm a letra `c`:

```bash
grep -c c comandos.txt
```

## 19. Selecionar colunas com `cut`

Crie um arquivo com informações de usuários:

```bash
cat > usuarios.txt <<'EOF'
carlos:professor:informatica
ana:aluna:linux
joao:aluno:redes
maria:aluna:banco-de-dados
EOF
```

Exiba o arquivo:

```bash
cat usuarios.txt
```

O separador dos campos é `:`. Para mostrar apenas o primeiro campo:

```bash
cut -d ':' -f 1 usuarios.txt
```

Saída esperada:

```text
carlos
ana
joao
maria
```

Para mostrar o segundo campo:

```bash
cut -d ':' -f 2 usuarios.txt
```

Para mostrar o primeiro e o terceiro campos:

```bash
cut -d ':' -f 1,3 usuarios.txt
```

As opções utilizadas são:

- `-d ':'`: define `:` como separador.
- `-f 1`: seleciona o primeiro campo.
- `-f 2`: seleciona o segundo campo.
- `-f 1,3`: seleciona o primeiro e o terceiro campos.

## 20. Encadear comandos com o operador `|`

O operador `|`, chamado de *pipe*, envia a saída de um comando para a entrada de outro.

Liste os arquivos e filtre apenas os nomes que contêm `.txt`:

```bash
ls -l | grep '.txt'
```

Mostre os arquivos do diretório atual e conte as linhas:

```bash
ls -1 | wc -l
```

Mostre apenas os nomes de arquivos que contêm a palavra `arquivo`:

```bash
ls -1 | grep arquivo
```

Use `cat`, `cut` e `grep` em sequência:

```bash
cat usuarios.txt | cut -d ':' -f 2 | grep aluno
```

Esse comando executa três operações:

1. Lê o arquivo `usuarios.txt`.
2. Seleciona o segundo campo.
3. Mostra apenas as linhas que contêm `aluno`.

## 21. Redirecionar a saída com `>`

Salve a lista de arquivos em um novo arquivo:

```bash
ls -l > lista-arquivos.txt
```

Leia o resultado:

```bash
cat lista-arquivos.txt
```

Salve apenas os usuários do arquivo:

```bash
cut -d ':' -f 1 usuarios.txt > nomes.txt
```

Confira:

```bash
cat nomes.txt
```

O operador `>` substitui o conteúdo do arquivo se ele já existir.

---

## 22. Acrescentar conteúdo com `>>`

Adicione uma nova informação ao arquivo:

```bash
echo "novo-usuario" >> nomes.txt
```

Confira:

```bash
cat nomes.txt
```

A diferença é:

```bash
comando > arquivo
```

Substitui o conteúdo do arquivo.

```bash
comando >> arquivo
```

Acrescenta a saída ao final do arquivo.

---

## 23. Usar entrada com `<`

O operador `<` envia o conteúdo de um arquivo para a entrada de um comando.

Conte as linhas do arquivo:

```bash
wc -l < nomes.txt
```

Ordene os nomes:

```bash
sort < nomes.txt
```

Salve os nomes ordenados:

```bash
sort < nomes.txt > nomes-ordenados.txt
```

Confira o resultado:

```bash
cat nomes-ordenados.txt
```

## 24. Combinar `grep`, `cut`, `sort` e `>`

Mostre apenas os nomes dos usuários do arquivo:

```bash
cut -d ':' -f 1 usuarios.txt
```

Ordene os nomes:

```bash
cut -d ':' -f 1 usuarios.txt | sort
```

Salve o resultado ordenado:

```bash
cut -d ':' -f 1 usuarios.txt | sort > usuarios-ordenados.txt
```

Leia o arquivo gerado:

```bash
cat usuarios-ordenados.txt
```

Mostre apenas os usuários que possuem a palavra `aluno` no segundo campo:

```bash
grep ':aluno:' usuarios.txt | cut -d ':' -f 1
```

Conte quantos usuários são alunos:

```bash
grep ':aluno:' usuarios.txt | wc -l
```

## 28. Conceitos essenciais

### Diretório atual

Representado por:

```bash
.
```

Exemplo:

```bash
./programa
```

### Diretório pai

Representado por:

```bash
..
```

Exemplo:

```bash
cd ..
```

### Diretório inicial

Representado por:

```bash
~
```

Exemplo:

```bash
cd ~
```

### Pipe

Representado por:

```bash
|
```

Envia a saída de um comando para outro:

```bash
ls -l | grep txt
```

### Redirecionamento de saída

Substitui o conteúdo do arquivo:

```bash
comando > arquivo
```

Acrescenta conteúdo ao arquivo:

```bash
comando >> arquivo
```

### Redirecionamento de entrada

Usa um arquivo como entrada do comando:

```bash
comando < arquivo
```

### Permissão de execução

Permite executar um arquivo como programa:

```bash
chmod u+x programa
```

Execução pelo diretório atual:

```bash
./programa
```
