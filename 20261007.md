# Aula: Kubernetes — Conceito e Operação de Pods

---

## 1. O que é um Pod?

Um **Pod** é a menor e mais fundamental unidade de implantação no Kubernetes. Ele representa um processo em execução no cluster.

* **Multi-container ou Single-container:** Um Pod pode conter apenas um contêiner (cenário mais comum) ou um grupo de contêineres intimamente ligados que compartilham os mesmos recursos.
* **Recursos compartilhados:** Todos os contêineres dentro do mesmo Pod compartilham:
* **Rede:** O mesmo endereço IP e espaço de portas (`localhost`).
* **Armazenamento:** Os mesmos volumes de dados persistentes.


* **Ciclo de vida efêmero:** Pods não foram feitos para durar para sempre. Se um Pod falhar ou for removido, ele não é reparado; em vez disso, o Kubernetes cria um novo Pod para substituí-lo.

---

## 2. Inicializar um Pod por linha de comando

Para criar e iniciar um Pod rapidamente utilizando a CLI (`kubectl`), utilize o comando `kubectl run`. Substitua `seu-nome` pelo seu nome:

```bash
kubectl run joao-nginx --image=nginx

```

* `joao-nginx`: Nome atribuído ao Pod.
* `--image=nginx`: Imagem do Docker Hub que será utilizada no contêiner.

---

## 3. Listar os Pods

Para verificar o status dos Pods em execução no namespace atual:

```bash
kubectl get pods

```

**Variações úteis:**

* Exibir mais informações (como IP do Pod e nó onde está executando):
```bash
kubectl get pods -o wide

```


* Acompanhar as alterações de status em tempo real:
```bash
kubectl get pods -w

```



---

## 4. Executar o Bash no Pod

Para abrir um terminal interativo dentro do contêiner que está rodando no Pod:

```bash
kubectl exec -it joao-nginx -- /bin/bash

```

* `-i` (*interactive*): Maintém a entrada padrão (STDIN) aberta.
* `-t` (*tty*): Aloca um terminal psuedo-TTY.
* `-- /bin/bash`: Especifica o comando a ser executado dentro do contêiner.

---

## 5. Testar a aplicação com `curl localhost`

Após acessar o terminal do Pod no passo anterior, execute o comando a seguir para testar a resposta do servidor web NGINX rodando localmente no contêiner:

```bash
curl localhost

```

**Saída esperada:** O código HTML da página padrão do NGINX (`<!DOCTYPE html><html>... Welcome to nginx! ...</html>`).

---

## 6. Sair do Pod

Para fechar a sessão do terminal interativo e retornar ao terminal da sua máquina/cluster sem parar o Pod:

```bash
exit

```

---

## 7. Apagar o Pod

Para remover o Pod do cluster e liberar os recursos alocados:

```bash
kubectl delete pod joao-nginx

```

Para confirmar a exclusão, liste os pods novamente:

```bash
kubectl get pods

```
