
# 🐧 Aula Prática: Linux — Gerenciamento de Pacotes e Serviços

**Data:** 03/06/2026  
**Duração:** 1 hora  

Hoje vamos dominar como instalar, remover e gerenciar programas no Linux usando o Ubuntu. Como vamos rodar tudo dentro de um container Docker temporário, todos vocês já entram com permissão de administrador (`root`). 

Têm licença poética para testar, errar e quebrar o sistema! Se algo der errado, basta fechar e abrir de novo que você ganha uma máquina limpa instantaneamente.

---

## 1. Subindo o nosso Laboratório

Abram o terminal e digitem o comando abaixo. Ele vai baixar e rodar um Ubuntu limpo em menos de 5 segundos:

```bash
docker run -ti --rm ubuntu bash

```

**O que esse comando faz?**

* **`run`**: Cria e roda o container.
* **`-ti`**: Abre o terminal interativo para podermos digitar os comandos.
* **`--rm`**: A mágica! Assim que você sair (`exit`), o container se autodestrói. Zero lixo no seu computador real.
* **`ubuntu bash`**: Usa a imagem oficial do Ubuntu e abre o interpretador de comandos (`bash`).

---

## 2. Gerenciamento de Pacotes (O Comando `apt`)

No Ubuntu, o nosso "App Store" de terminal se chama **APT** (Advanced Package Tool). É com ele que baixamos e apagamos programas.

### Passo 1: Atualizando o "Catálogo"

Um container Ubuntu novo vem "cego". Ele não sabe quais programas existem na internet. O primeiro comando sempre deve ser para atualizar essa lista:

```bash
apt update

```

### Passo 2: Procurando um Programa

Vamos ver se o nosso servidor web (Nginx) e nossa ferramenta de download (Curl) existem no catálogo:

```bash
apt search nginx
apt search curl

```

### Passo 3: Instalando os Programas

Agora vamos instalar de fato os pacotes. Vamos aproveitar e instalar também o `python3` e o `wget`, que usaremos mais para frente. O parâmetro `-y` já responde "sim" para a confirmação de espaço em disco.

```bash
apt install nginx curl python3 wget nano -y

```

### Passo 4: Removendo Programas (As 3 Formas)

Instalou algo errado? O APT tem três formas de limpar a casa (vamos usar o `nano` como exemplo):

1. **Remove apenas o programa** (Mantém os arquivos de configuração, caso queira reinstalar depois):
```bash
apt remove nano

```


2. **Remove tudo** (Apaga o programa e deleta as configurações. É a limpeza profunda):
```bash
apt purge nano

```


3. **Limpando as dependências órfãs** (Limpa as bibliotecas de sistema que ficaram sobrando depois de uma remoção):
```bash
apt autoremove -y

```

## 3. O Truque do Systemctl no Docker

No mercado de trabalho, o padrão para ligar e desligar serviços no Linux é o comando `systemctl`. Porém, o Docker foi feito para ser muito leve e não roda o gerenciador de sistema padrão (Systemd). Se você tentar usar `systemctl start nginx` agora, vai tomar um erro.

Para treinar com os **comandos reais de mercado**, vamos usar um truque avançado: um script em Python do GitHub que "finge" ser o Systemd dentro do Docker!

### Substituindo o systemctl original:

Vamos baixar o script oficial e jogá-lo por cima do comando quebrado do Docker, dando permissão de execução logo em seguida:

```bash
wget [https://raw.githubusercontent.com/gdraheim/docker-systemctl-replacement/master/files/docker/systemctl3.py](https://raw.githubusercontent.com/gdraheim/docker-systemctl-replacement/master/files/docker/systemctl3.py) -O /usr/bin/systemctl
chmod +x /usr/bin/systemctl

```

Pronto! Agora o nosso container aceita os mesmos comandos de um servidor de grande porte.

## 4. Gerenciamento de Serviços

Com o nosso ambiente pronto, vamos colocar o servidor Nginx para rodar no background.

### Passo 1: Verificando o Status do Servidor

O Nginx está instalado, mas não liga sozinho. Vamos confirmar:

```bash
systemctl status nginx

```

*(Aperte a letra **`q`** para sair da tela de status e voltar ao terminal).*

### Passo 2: Iniciando o Serviço

Vamos ligar o nosso servidor web!

```bash
systemctl start nginx

```

Rode o comando de status novamente e veja que a bolinha agora está verde e "active".

### Passo 3: Testando na Prática

Vamos usar o `curl` para simular um navegador acessando o nosso próprio servidor.

```bash
curl http://localhost

```

Se a tela encher de código HTML dizendo **"Welcome to nginx!"**, sucesso! Você instalou e configurou um servidor via linha de comando.

### Passo 4: Reiniciando e Parando

Quando alteramos arquivos de configuração, precisamos reiniciar o serviço para as mudanças terem efeito:

```bash
systemctl restart nginx

```

E para desligar o servidor definitivamente:

```bash
systemctl stop nginx

```

## 5. Encerrando o Laboratório

Para provar que o uso de containers Docker é maravilhoso para estudos, digitem o comando para sair da máquina:

```bash
exit

```

**O que aconteceu?**
Sua máquina virtual inteira acabou de ser apagada da existência. Todos os testes, instalações e arquivos temporários sumiram, graças ao parâmetro `--rm` que usamos no início da aula.
